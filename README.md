# Hexotis
Hexotis notre projet de SI de terminale (2016?). L'objectif était de faire un instrument de musique intuitif. 

Le design se base sur des pads hexagonaux sensible à la préssion. 
La boite avait été imprimée en 3d PLA, les touches en imprimées avec un filament souple.
L'organisations était pensée pour faire différentes gammes avec la disposition naturelle des doigts. 

Nous avions choisi d'utiliser des capteurs piezos pour les touches.

2 arduinos méga et 1 uno pour gérer tous les capteurs et l'audio.
